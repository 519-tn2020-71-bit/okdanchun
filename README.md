# 연광정의 북소리

고전 소설 「옥단춘전」을 바탕으로 한 수업용 서사 RPG입니다.

- 바로 하기: https://519-tn2020-71-bit.github.io/okdanchun/
- 이혈룡 편 6장, 옥단춘 편 4장
- 붉은 낙관(本)이 찍힌 문장은 수업 자료인 「옥단춘전」 현대어 번역본의 문장입니다. 거지꼴로 돌아온 혈룡을 옥단춘이 맞는 대목과 연광정에서 북소리가 울리는 대목은 EBS 수능특강에 실린 지문의 문장이며, 화면에 ‘EBS 수능특강 지문’ 표시가 붙습니다.
- 그림은 AI로 생성했고, 배경음과 효과음은 게임 안에서 직접 합성합니다.

만든이: 경포고등학교 한예지 (게임 코드는 AI 도구 Claude와 함께 만들었습니다)
